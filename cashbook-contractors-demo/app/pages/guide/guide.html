Quick start

Follow these eight steps once and the rest of the app will make sense.

  1. Create the client. Sidebar Records › Client Portal, press Create New Profile, fill in the name (required) and Save Client.
  2. Add the project. Open the client, go to the Projects tab and press + Add project. Enter the name, budget and start date.
  3. Open the project. In the Projects tab press Open on the project. The sidebar now shows a Current Project menu.
  4. Add your crew and their pay rates. Project 201 Files › Add Person. Fill in the daily, hourly and OT rates.
  5. Set up the Program of Works. Progress & Timeline › Add Program of Work, then add items with planned start and finish dates.
  6. Record the money. Payroll each day, then payments received and expenses in Income & Expenses.
  7. Check how you are doing. The Dashboard and Portfolio show budget, progress and what is due.
  8. Back up. Gear icon › Export Backup File. Do this at least once a week.

Tip: when you are done with a project, press Close Project on the coloured card at the top of the sidebar.

Finding your way

  • Sidebar (left). Overview has Dashboard and Portfolio. Records has Master Data, Client Portal and Human Resources. Tools has Settings, Data Transfer, User Guide and About.
  • Inside a project. The sidebar shows a coloured card with the client, project and project code, then the Current Project menu: Overview, Income & Expenses, Materials & Procurement, Payroll, Project 201 Files, Progress & Timeline, S-Curve & Forecast and Cheque Register.
  • ☰ button. Collapses or opens the sidebar. The app remembers your choice.
  • Gear icon (top right of each page). Export Backup File, Restore Exported Backup, Print, Activity Log, Light/Dark Mode and Factory Reset.
  • Dark mode. Gear icon, or Settings › Appearance.

Project pages open only from inside a client's portal. If you open one from an old bookmark, the app takes you to the Client Portal to pick the client first.

Clients & Client Portal

The Client Portal is the door into a client. Everything for that client lives behind it.

Create a client

  1. Records › Client Portal › Create New Profile.
  2. Enter the client name (required). Business name, contact number, email, TIN and address are optional. The TIN is used when you send data to the Accountant Edition.
  3. Optional: add a logo and pick a brand colour. The client's status page uses them.
  4. Press Save Client.

Open a client

Type in Find a client or use the list, then press Open Portal. You get three tabs:

  • Status is the client-facing view with progress and payments. It never shows your costs, and you can print it with Print status.
  • Profile lets you edit the details, logo and brand colour, or archive the client.
  • Projects lets you add, edit, archive or restore projects, and Open a project's full workspace.

Tip: archiving hides a client or project without deleting anything. You can restore it later.

Projects

  1. From the client's Projects tab press + Add project (or use Client Portal › Add / edit projects).
  2. Choose the client. Fill in the project name, site address, budget, status, start date, target end date and notes. Name, budget and start date are required.
  3. Press Save Project. Each project gets a project code such as PRJ-2026-001.

Status is Ongoing, On Hold or Completed. Change it any time by editing the project. The Project Overview page shows the budget, income recorded, expenses recorded, remaining budget, timeline and a short Recent Activity list.

Dashboard

Your daily view. Use Client to choose All Clients or one client, and Featured project to choose which project is shown (Auto picks the most recently active one). The figures follow your choice.

  • Featured project with its progress and a View Projects button that lists every project with status and progress.
  • Budget Summary: Cash In, Cash Out, Collectibles (budget not yet paid) and Payables (unpaid PO installments and issued cheques not yet cleared). Details breaks it down by project.
  • Timeline Status: the real timeline against the contract timeline. Details shows each project.
  • Due This Week: what needs attention soon. Click an item to go to that project.

Portfolio

All projects at a glance, side by side. Overview › Portfolio. Filter by client at the top.

  • Projects by status, number delayed, total budget and cost.
  • Charts for status, budget distribution, monthly progress trend and planned against actual progress.
  • SPI (schedule performance) and CPI (cost performance). Above 1.0 is good; below 1.0 means behind schedule or over cost.
  • An All Projects table at the bottom.

Crew & pay rates (Project 201 Files)

Payroll cannot be recorded for someone without a pay rate, so set the crew up first. Current Project › Project 201 Files.

  1. Press Add Person, or Add from Company 201 to copy someone from Human Resources.
  2. Choose the worker type: Worker, Employee or Subcontracted. Subcontracted workers have no rank or 201 file.
  3. Under Pay rates enter the Daily rate, Hourly rate and OT rate (per hour).
  4. Optional: use Role Hierarchy and Add Role to list roles, top role first. The crew list follows that order.

Press Export to Excel to download the crew list.

If you leave a rate empty, the app works it out: daily rate ÷ 8 for the hourly rate, and 125% of the hourly rate for overtime.

Payroll

Current Project › Payroll. Record each day, check the log, then post the pay to Cash Out.

Record a day (Daily Timesheet)

  1. Choose the date. Use the arrows to move one day.
  2. For each person tap Absent, ½ Day or 1 Day. Add overtime hours if any. For a partial day type the regular Hours worked instead.
  3. Shortcuts: Mark All Present and Same as Last Day. Clear starts over.
  4. Press Save Day. Pay is calculated from each person's rates.

A person can be recorded only once per date. To add extra pay or deductions for someone, use the Single Entry tab.

Payroll Log

Entries are listed 30 per page, newest first. Click a row to see its pay breakdown. Search by worker, date or note, and filter by All, Unposted or Posted. Expand Page opens every row.

Pay the crew (post to Cash Out)

  1. In the Cash Out card choose a period: This Week, Last Week, 1st–15th or 16th–End, or pick your own dates.
  2. Check the preview.
  3. Press Post Payroll to Cash Out. The payroll is added to your expenses once, so it cannot be counted twice.

Income & Expenses

Current Project › Income & Expenses. This is the project's cashbook.

  1. Press Add Entry and choose Income or Expense.
  2. Enter the date, amount, description and a reference number (such as an OR or invoice number).
  3. Pick a category. Income: Billed to Client, Down Payment, Progress Payment, Final Payment, Other. Expense: Labor, Materials, Equipment, Permits, Subcontractor, Other.
  4. Press Save Entry.

Filter the list with All, Income or Expense. Posted entries are corrected by a reversal with a reason, so the history stays complete. Tick Show reversed to see them.

Tip: payroll, material orders and cleared cheques post here for you. You do not need to type them again.

Materials & Purchase Orders

Current Project › Materials & Procurement.

Budget and stock

  1. Enter the Materials Budget and press Save Budget.
  2. Press Record Movement. Enter the material name, direction (in or out), date, quantity, unit and unit cost. For an out movement give a reason, such as "Used on site".
  3. Stock on Hand shows what is left. The app will not let you take out more than you have, and a material must always use the same unit.
  4. To count a delivery as an expense, tick it and press Post selected to Cash Out.

Purchase orders

  1. Press New Purchase Order. Enter the material, supplier, quantity and total, and split the payment into installments with due dates if you pay in parts.
  2. When you pay an installment, press Mark paid. That posts one cash-out, and Undo reverses it.
  3. When the goods arrive, press Mark delivered. This adds the stock automatically and does not post cash again.

Unpaid installments appear as Payables and in Due This Week on the Dashboard.

Cheque Register

Current Project › Cheque Register. Tracks cheques you issue and cheques you receive.

  1. Press Add Cheque and choose the type: Issued (you pay) or Received (you are paid).
  2. Enter the cheque number, bank, payee or payer, amount and maturity date.
  3. Press Save Cheque. The same cheque number for the same bank and direction cannot be entered twice.
  4. Later, open the status menu on the cheque and choose Cleared or Bounced. Clearing posts the cash movement once.

The top tiles show cheques that have Matured and those Maturing in 7 days, with amounts. Filter by All, Needs Attention, Pending, Cleared or Bounced, and search by payee, number, bank or note.

Progress & Timeline

Current Project › Progress & Timeline. Progress is measured from the work you plan and complete, so the numbers are honest.

  1. Press Add Program of Work (for example "Foundation"). Give it start and end dates inside the project dates.
  2. Inside it press Add Sub-Program Item. Give each item a name and a planned start and finish within its program.
  3. As work finishes, open the item and press Mark Item Complete, enter the Date Completed and press Confirm Complete.
  • Planned progress comes from the item schedules. Actual progress comes from completed items.
  • The chart compares Planned (orange) and Actual (blue), and states whether you are ahead, behind or on schedule.
  • If the client agrees to a new finish date, use Save Approved Override. Enter the new target date and the reason. Clear Override removes it.

If something is missing, the page tells you what to add (for example "Add start and finish dates to 2 sub-items") instead of showing a wrong percentage.

S-Curve & Forecast

Current Project › S-Curve & Forecast. It shows where the project is heading.

  • Progress S-Curve: planned, actual and forecast progress.
  • Financial S-Curve: planned value, earned value and actual cost.
  • Variance, monthly rate, remaining duration, forecast completion, delay forecast, SPI, CPI and forecast final cost.

A figure is left blank, with the reason, when it cannot be trusted yet: no schedule, no costs, or less than two weeks of progress. Fill in the Program of Works and record some costs and it fills in.

Human Resources

Records › Human Resources. The company's own 201 files.

  1. Press Add Employee. Enter the name, rank, position, hire date, contact details and government numbers.
  2. Add documents: 2x2 photo, 201 details form, government ID, employment contract, credentials, clearance or other. The checklist shows which required documents are still missing.
  3. Print the 201 sheet, or use Export to Excel for one person or everyone.

The Excel file holds the details and document names, not the scanned files. Scanned documents are kept separately and are included in Export Backup File.

Master Data

Records › Master Data. Every client and their projects in one list. This page is view-only: use View details on a client for a full summary you can print. New clients are created in Client Portal.

Data Transfer

Tools › Data Transfer.

  • Send to Accountant: choose the clients to include and press Export Transfer Package (.cftransfer).
  • Import Package: load a .cftransfer file from Cashbook for Business or the Accountant Edition into a chosen project, review it, then press Import Entries.
  • Full Data Package: Export Full Data and Import Full Data to move everything to another computer. Import offers Merge (add to what you have) or Replace (overwrite).

Backup & Settings

  1. Gear icon (or Settings › Backup & Restore) › Export Backup File. Save the file on a USB drive or cloud folder, not only on this computer.
  2. To restore, press Restore Exported Backup and choose the file. It replaces all current clients and projects, and the app asks you to confirm first.

The app also keeps automatic restore points on this computer, but scanned HR documents are not in them. Export Backup File is what protects them.

Settings also has Appearance, the Activity Log (what changed and when), Contact and Factory Reset.

Careful: Factory Reset erases everything. Export a backup first.

Printing & PDF

  1. On any page press Ctrl + P, or use gear icon › Print. A preview opens.
  2. Under Print area tick only the cards, sections or tables you want. The preview updates at once. Select all and Clear help.
  3. Optional: turn on the signature block (Prepared by, Checked by, Approved by) and type names and positions. The app remembers them.
  4. Use the zoom and page buttons to check the pages, then print or save as PDF.

Common questions

It says "Set a pay rate" when I save payroll.
Open Project 201 Files, edit that person and fill in the daily, hourly or OT rate.
It says a worker is "already recorded for this date".
Each person can have one payroll entry per day. Edit the existing entry in the Payroll Log instead.
The progress percentage is missing.
Planned progress needs project start and end dates, a Program of Works and dates on every item. The message on the page says which one is missing.
I opened a project page and ended up in the Client Portal.
Project pages open only from inside a client's portal. Pick the client, open the Projects tab and press Open.
I recorded something by mistake.
Posted entries are not deleted. Reverse them with a reason, or edit them where the page allows it. The Activity Log keeps the full history.
Where did my data go after a restore?
A restore replaces current data with the file you chose. The app makes a safety copy of what was there just before, so stop, do not restore again, and check that you chose the right backup file.
