Try Cashbook for Contractors — no install needed

This is the real program running in your browser, loaded with a sample construction business: 3 clients, 4 projects, payroll, purchase orders, cheques, progress schedules and HR files.

  • Add, edit and delete anything. Every feature works.
  • Nothing is saved. When you press Reset demo, refresh, or close the tab, everything returns to the original sample data.
  • Tip: open Client Portal → pick a client → Projects → Open to enter a project workspace.
⬇ Download full version
The full version installs on Windows and keeps your data on your computer.

What can I try?

  • Dashboard & Portfolio — budget summary, timeline status, planned vs actual progress.
  • Client Portal — pick a client, then Projects → Open to enter the project workspace.
  • Inside a project — Income & Expenses, Materials & Procurement (purchase orders, installments, stock), Payroll (daily timesheet), Project 201 Files, Progress & Timeline, S-Curve & Forecast, Cheque Register.
  • Human Resources — company 201 files and required-document checklists.
  • Print — press the print button on any page for the print preview, print area and signature block.
  • Data Transfer — export an Excel/backup file; it downloads to your computer, but nothing is kept in the demo.

Please open this demo from a web address

This page was opened directly from a file on your computer, and browsers block the demo from running that way. Upload the folder to any web host (for example GitHub Pages, Netlify or your own website), or run a small local server, then open the page again.
